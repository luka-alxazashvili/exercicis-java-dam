# Exercicis Java – DAM

Exercicis de programació en Java realitzats durant el primer curs del CFGS de Desenvolupament d'Aplicacions Multiplataforma (STUCOM).

## Exercicis

| Exercici | Descripció |
|---|---|
| `EJ_1_pila` | Simulació d'una pila (apilar, desapilar, mostrar primer i últim) amb un array d'enters. |
| `EJ_2_reloj` | Rellotge digital que permet avançar i endarrerir hores i minuts, guardant cada dígit en un array. |
| `EJ_3_PokeDex` | Pokédex de consola per afegir, cercar, eliminar i comptar Pokémon, amb validació de posicions. |

## Conceptes treballats
- Arrays i `Arrays.fill`
- Mètodes estàtics i modularitat
- Menús de consola amb `Scanner`, `switch` i `do-while`
- Validació de dades d'entrada

## Tecnologies
Java · NetBeans
